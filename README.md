# Personal Profile Flutter App

A three-page Flutter assignment app for **معاذ الدسوقي شعبان**.

## Pages and navigation

- **Home:** profile photo, name, developer level, phone number, and a button to About.
- **About:** short introduction and a button to Contact.
- **Contact:** contact page with a button back to Home.
- A bottom navigation bar also lets you move directly between all three pages.

## Run

From this folder, run `flutter pub get` and then `flutter run`.

The profile photo is bundled locally at `assets/IMG_20260820_214150.jpeg`.
